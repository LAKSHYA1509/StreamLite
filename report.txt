Commands to run the live server in this project:

1. Start Redis service (from commands.txt):
   sudo service redis-server start

2. Start Kafka (from commands.txt):
   cd C:\kafka\kafka_2.13-4.1.0
   bin\windows\kafka-storage.bat format -t XMGWVC8LRxaLXW2dE5hu1g -c config\server.properties
   bin\windows\kafka-server-start.bat config\server.properties

3. Run the Spring Boot application (using Maven wrapper):
   mvnw spring-boot:run

4. Start the live streaming (using the batch file):
   start_live.bat

Additional: To run Locust load testing for VOD streaming:

5. Install Locust (if not already installed):
   pip install locust

6. Run Locust with the VOD test script:
   locust -f vod_test.py --host=http://localhost:8000

7. Open browser to http://localhost:8089 to configure and start the load test.
